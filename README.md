# 小米风扇网页控制器（Web Bluetooth）

在浏览器里直连小米风扇（Mi Standard BLE 协议），不依赖米家 App 即可开关机、调风速、开关夜灯、设定时。

- 纯前端：`index.html` 单文件，无需构建、无需安装依赖
- 协议自行实现：Mi 认证（HKDF/HMAC）→ 传输层分帧 → AES-CCM 加密 → MIoT 属性读写
- 附带 `proxy.js`：本机代理，登录小米云帮你在设备列表里一键取出 BLE token

> 仅供学习和个人自用。协议细节参考了 [E7G/xiaomi-ble-control](https://github.com/E7G/xiaomi-ble-control) 与
> [PiotrMachowski/Xiaomi-cloud-tokens-extractor](https://github.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor)。

## 已验证设备

| 型号 | 广播名 | 说明 |
| --- | --- | --- |
| J15SL | `als1.fan.j15sl` | 已验证开关/风速/夜灯/定时 |
| F11 / F11 Pro | `szxzh.fan.*` | 走另一套属性表，带电量/充电状态 |

其他小米风扇可尝试：连接时若设备名不是上面这些，默认按 F11 属性表处理，可能部分功能无效。

## 快速开始

### 1. 启动本地服务（推荐）

浏览器要求 Web Bluetooth 只能在**安全上下文**中使用，`file://` 直接打开通常拿不到蓝牙。

```bash
node proxy.js
# 默认 http://127.0.0.1:8765
# 改端口：PORT=9000 node proxy.js
```

然后访问 <http://127.0.0.1:8765>。

需要 Node.js 16+，`proxy.js` 只用内置模块，不用 `npm install`。

### 2. 拿到 BLE token

**方式 A：从米家云端提取（需要本机跑着 `proxy.js`）**

1. 页面底部「云端账号」里填小米账号密码，点登录（密码只发往 `127.0.0.1`，不落地存储）
2. 设备列表出现后，找到你的风扇，点「填入」

**方式 B：手动填**

如果你已经有了该设备的 BLE beaconkey（24 位十六进制），直接粘到「BLE Token」输入框。

### 3. 连接并控制

点「选择设备并连接」，在浏览器弹窗里选你的风扇。之后：

- 中间电源键：开 / 关机
- 左侧转盘或滑杆：调风速（关机状态下调风速会自动开机）
- 1–5 档位：快捷风速（1% / 25% / 50% / 75% / 100%）
- 夜灯开关、关机定时

## token 自动带上（收藏免填写）

token 会自动写进地址栏，即 `http://127.0.0.1:8765/?token=<24位十六进制>`。
把它加进收藏夹，下次打开就自动填好，不用再找 token。

同时也会存一份在浏览器 `localStorage` 里。**这个链接等于设备密钥，不要分享给别人。**

## 定时说明

定时是设备端的关机定时，由设备自己倒计时：

- J15SL：单位**小时**，1–24，0 表示关闭（固件限制，无法设半小时）
- F11：单位**分钟**，上限 480

操作方式：用 `−`/`+` 或直接输入时长 → 点「开始定时 N 小时」。
定时生效后按钮会变成绿色并显示剩余时间，**再点一次即取消定时**。

## 已知限制

- 仅 Chrome / Edge 等基于 Chromium 的浏览器支持 Web Bluetooth，Safari / Firefox 不行
- 同一时间只能有一个程序占用设备蓝牙，手机米家 App 在连着时电脑连不上
- J15SL 固件没有电量/充电属性，界面上这两张卡片会自动隐藏
- 小米账号登录若开了两步验证，目前拿不到 token，只能走方式 B

## 配置

| 位置 | 作用 |
| --- | --- |
| 页面「代理地址」 | 云端提取用的代理地址，默认 `http://127.0.0.1:8765` |
| 日志卡「原始通知」 | 勾选后打印蓝牙原始报文，排错/适配新型号时用 |
| `proxy.js` 的 `PORT` | 环境变量，改监听端口 |

新增型号支持：在 `index.html` 的 `PROFILES` 里加一份属性表（siid/piid、速度编码方式、定时单位、有无电池），
再在 `detectProfile()` 里按设备名匹配即可。
