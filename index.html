连接风扇
连接需要使用「Mi Standard BLE 认证 token」，不是网关 token 或 MIoT 的 OAuth token。 没有的话可用下方的云端提取，或手动从已配对的米家设备获取。
Token 会自动写进地址栏（?token=…），填好一次后收藏本页，下次打开即自动带上，无需再填。
搜不到设备时：① 关闭手机上已连接该风扇的米家/蓝牙；② 确认 Windows 蓝牙已开启； ③ 用 http://127.0.0.1:8765 打开本页（先运行 node proxy.js），file:// 下部分设备不广播名字会被过滤掉。
小米云提取 Token可选
代理地址设置 / 说明
浏览器无法直连小米云（CORS），需先在本机运行附带的小代理：
node proxy.js
账号密码只在本机 127.0.0.1 与小米服务器之间传递，不会被存盘。 开启图形验证码或邮箱二次验证的账号，请先在米家 App / 浏览器登录一次再试。
